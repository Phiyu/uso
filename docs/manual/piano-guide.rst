给钢琴演奏者的社团指南
======================

钢琴演奏者可以参加演奏部的音乐会、音乐沙龙、练琴值班和其他团务活动。演奏部群号为 925342961。

练琴地点
--------

* **东活 711**：有管弦乐团钢琴，无需预约即可练习；中央大厅另有公用钢琴。
* **西活 302**：需按规定领取钥匙，或参加练琴值班后使用。使用时请关灯、关空调并归还钥匙。
* **一教 1102**：教室无人时可以使用公用钢琴。
* **中区艺术中心**：关注“中国科大艺术教学”公众号后预约琴房。

音乐会与活动
------------

新年音乐会、春季音乐会和室内乐音乐会都会征集钢琴独奏或合奏节目。钢琴同学也可以加入谱务小组、文案组，或参与音乐沙龙、主题讲座和乐团排练。

无论是继续练琴、登台演出，还是结识音乐同好，乐团都欢迎你的加入。
