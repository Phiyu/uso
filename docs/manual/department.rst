校学生管弦乐团部门简介
========================

中国科大学生管弦乐团是校内西洋音乐类社团，活动包括管弦乐团排练、钢琴演奏、音乐沙龙、音乐会以及音乐文化推广。

演出部门
--------

乐团部负责管弦乐团曲目，分为弦乐、木管、铜管和打击四个声部，每周进行大团排练和声部小排。

演奏部面向钢琴及其他独奏乐器演奏者，负责音乐会小节目、音乐沙龙和练琴值班等活动。

其他部门
--------

* **谱务部**：编写、修改排练曲目，提供扒谱和制谱支持。
* **宣传组**：制作海报、展架、节目单及公众号宣传素材。
* **文案组**：撰写曲目介绍、赏析文案和侧屏导赏内容。
* **财务部**：负责报销和发票等财务工作。
* **后勤组**：负责乐器、谱架及演出物资搬运。
* **新媒体组**：运营 QQ 空间、微信公众号、Bilibili 等平台。
* **年轻人的音乐课**：组织面向全校的音乐赏析和乐器介绍讲座。

无论想在舞台上演奏，还是参与幕后工作，USO 都欢迎你的加入。
